# Retail Sales Sampling Analysis

## Overview
This project evaluates different statistical sampling methods to estimate retail sales totals and improve estimation accuracy. The analysis compares sampling strategies and quantifies uncertainty using statistical inference techniques.

## Objectives
- Compare sampling strategies for retail data
- Estimate population totals using sampling methods
- Compute confidence intervals
- Evaluate estimator performance

## Methods Used
- Simple Random Sampling
- Stratified Sampling
- Ratio Estimation
- Confidence Interval Estimation
- Variance Estimation

## Tools & Technologies
- R
- Quarto
- Statistical Sampling Methods
- Data Visualization

## Files
- `sampling_methods_retail.html` — Full statistical analysis report

## Key Insights
- Stratified sampling improved estimation accuracy
- Variance reduction observed across structured sampling
- Confidence intervals quantified uncertainty in estimates
